# 📚 تطبيق أدبي - Adabi App

**الرفيق الأكاديمي لطلاب الأدب العربي والتعليم الأساسي**

تطبيق ويب متكامل مصمم خصيصاً لطلاب تخصص الأدب العربي مع تركيز على التعليم الأساسي. يحتوي التطبيق على 6 شاشات تفاعلية تغطي جميع احتياجات الطالب الأكاديمية.

---

## ✨ المميزات

### 📱 الشاشات المتاحة:
1. **الرئيسية** - لوحة تحكم مع تقدم الفصل، اختصارات سريعة، حصص اليوم، والإعلانات
2. **المواد الدراسية** - قائمة كاملة بالمواد مع شريط تقدم لكل مادة
3. **الجدول الأسبوعي** - عرض مرئي أنيق للمواعيد مع خط زمني ملون
4. **الامتحانات والواجبات** - إحصائيات وقائمة بالمهام القادمة مع عد تنازلي
5. **البحث المتقدم** - شريط بحث مع فلاتر وعرض نتائج كتب ومراجع
6. **الملف الشخصي** - إحصائيات أكاديمية، نشاط أسبوعي بياني، إنجازات، وإعدادات

### 🎨 الهوية البصرية:
- **الألوان**: أزرق بحري داكن عميق (#0f1e36) + ذهبي فاخر (#c9a227) + لمسات فيروزي وبنفسجي
- **الخط**: خط Cairo العربي الحديث
- **التصميم**: عربي كامل من اليمين إلى اليسار (RTL)
- **التأثيرات**: انتقالات سلسة، تأثيرات عند التحويم، تصميم متجاوب

## 🚀 الطريقة الأولى: الرفع على GitHub Pages

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. افتح حسابك على [GitHub](https://github.com)
2. اضغط على **New Repository**
3. اسم المستودع: `adabi-app`
4. اختر **Public**
5. اضغط **Create Repository**

### الخطوة 2: رفع الملفات
يمكنك الرفع بطريقتين:

#### الطريقة أ: الرفع المباشر من المتصفح (الأسهل)
1. في صفحة المستودع الجديد، اضغط على **uploading an existing file**
2. اسحب وأفلت جميع ملفات المجلد (`index.html`, `style.css`, `app.js`, `manifest.json`)
3. اضغط على **Commit changes**

#### الطريقة ب: باستخدام Git (للمتقدمين)
```bash
# افتح مجلد التطبيق
cd adabi-app

# تهيئة Git
git init
git add .
git commit -m "إصدار أولي من تطبيق أدبي"

# ربط بالمستودع البعيد (استبدل USERNAME باسم المستخدم الخاص بك)
git remote add origin https://github.com/USERNAME/adabi-app.git
git branch -M main
git push -u origin main
```

### الخطوة 3: تفعيل GitHub Pages
1. في صفحة المستودع، اذهب إلى **Settings**
2. من القائمة اليمنى اختر **Pages**
3. في **Source** اختر: `Deploy from a branch`
4. في **Branch** اختر: `main` و `/ (root)`
5. اضغط **Save**
6. انتظر بضع دقائق، ثم ستحصل على رابط التطبيق على شكل:
   `https://USERNAME.github.io/adabi-app/`

## 📦 الطريقة الثانية: تحويل التطبيق إلى ملف APK

هناك عدة طرق موثوقة لتحويل تطبيق الويب إلى ملف APK:

### الخيار أ: PWA Builder (الأسهل والأسرع)
1. اذهب إلى [PWA Builder](https://www.pwabuilder.com/)
2. أدخل رابط تطبيقك على GitHub Pages
3. اضغط **Start**
4. الموقع سيفحص التطبيق ويعطيك تقييماً
5. اضغط على زر **Build** في قسم Android
6. اختر **Download** للحصول على ملف APK
7. انسخ الملف إلى هاتفك وقم بتثبيته

### الخيار ب: باستخدام Capacitor (للمطورين)
```bash
# 1. إنشاء مجلد جديد
mkdir adabi-android
cd adabi-android

# 2. تهيئة مشروع Capacitor
npm init -y
npm install @capacitor/core @capacitor/cli
npx cap init

# 3. أضف منصة أندرويد
npm install @capacitor/android
npx cap add android

# 4. انسخ ملفات تطبيقك إلى مجلد www/
# انسخ index.html, style.css, app.js, manifest.json إلى مجلد www/

# 5. مزامنة وبناء التطبيق
npx cap sync
npx cap open android
```
سيفتح هذا Android Studio حيث يمكنك بناء ملف APK مباشرة.

### الخيار ج: باستخدام Cordova
```bash
# 1. تثبيت Cordova
npm install -g cordova

# 2. إنشاء مشروع جديد
cordova create adabi-cordova com.example.adabi "أدبي"
cd adabi-cordova

# 3. إضافة منصة أندرويد
cordova platform add android

# 4. انسخ ملفات تطبيقك إلى مجلد www/
# (استبدل محتوى www/ بملفات تطبيقك)

# 5. بناء التطبيق
cordova build android
```
سيتم إنشاء ملف APK في: `platforms/android/app/build/outputs/apk/debug/`
